# Fork notice

This repository is an independently maintained, upstream-aligned fork of [`godotengine/godot-cpp`](https://github.com/godotengine/godot-cpp). It preserves upstream history and publishes reproducible-structure binary convenience packages for a reviewed compatibility matrix.

The Godot Engine project does not publish or support these fork-specific binary packages. General source fixes should be contributed upstream. Fork-specific additions are limited to public release tooling, package contracts, verification, and generally useful temporary patches recorded in package metadata.

See `docs/releases/binary-packages.md` for the package contract, `docs/releases/release-policy.md` for publication controls, and `docs/releases/upstream-sync.md` for lineage policy.
